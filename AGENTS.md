# os25 harness development

Read README.md, SETUP.md and the relevant fullframe/README.md before changes.
The initial supported workload is Butterscotch, running both Undertale and
Deltarune Chapter 1. Do not imply other cores are validated.

Work only in this repository. Never modify the game-port active checkout,
original SDK/OS roots or an SD card. Use the Python launchers, which mount only
this repository in Docker. Keep inputs/, captures/, build/, generated bytecode
fixtures and .bootstrap-* private and ignored. Never stage them or bypass hashes.

Dependency pins and file hashes are deliberate. Investigate mismatches; changing
a pin requires a separately recorded baseline and recaptured evidence. QEMU/RTL
state hashes contain pointers and compare the same binary, not candidate builds.
For behavior-preserving changes compare pixels, PCM and relevant game values
independently across baseline and candidate captures.

Run the affected verification before claiming success. Bootstrap changes require
the import tests plus a real frozen-input import. Firmware changes need host
reference/negative checks and affected RTL replay. Full-frame changes need repeat
capture agreement, replay, negative oracles and the complete matrix report.
Label timings simulated; physical Pocket performance remains separately tested.

Use conventional, GPG-signed commits. No push, publication, remote creation or
deployment is implied by local development. The skill under
.agents/skills/os25-harness/SKILL.md contains the workload and fidelity guidance.
